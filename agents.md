# Publishing BestPicks Reviews

This repository serves the public site from GitHub Pages. Preserve current URLs. The private application and legacy publishing engine are separate projects; do not migrate hosting or run a bulk regeneration as part of routine content work.

## Editorial requirements

- State what was researched or tested and what remains unknown. Never invent first-hand tests, measurements, qualifications, ratings, review counts, quotations or source checks.
- Verify product names, model numbers, specifications and purchase destinations against primary sources. Keep source links and the actual review date with substantive corrections.
- Recommend by use case and explain limitations. Include suitable non-affiliate alternatives. Commission availability alone is not a reason to rank a product first.
- Use an Awin link only for a confirmed joined advertiser and a verified product destination. Preserve publisher ID and meaningful click references. Do not follow trackers repeatedly as link tests.
- Do not publish unverified prices or stock in structured data. Article markup must describe the visible page; ratings require visible, defensible evidence.
- Keep private analytics exports, financial information, credentials and operational audits out of this public repository.

## Required checks

Run the commands in `scripts/README.md`. Keep all baseline review URLs discoverable. Regenerate the sitemap after adding or retiring canonical pages; do not fabricate `lastmod` dates. Keep redirects out of the sitemap and map only to genuinely equivalent pages.

Use the shared consent-aware analytics loader once on full content pages. Do not add page-specific Google tags or report affiliate clicks as purchases. Verify mobile navigation, tables, search and merchant link destinations when changing them.

The offline validator does not verify product facts, advertiser approval, live Google indexing or real commission attribution. Check those independently and report limits honestly.
